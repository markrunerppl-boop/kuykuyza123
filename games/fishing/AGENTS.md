# AGENTS.md - คู่มือและกฎการทำงานสำหรับ AI Agent (Kuykuy Hub Project)

เป้าหมาย: เพิ่มฟังก์ชันตามที่ระบุให้สำเร็จ โดยใช้เวลาและทรัพยากรให้น้อยที่สุด โดยไม่ลดคุณภาพและความถูกต้องของระบบเดิม

## 1. กฎการตรวจสอบและเตรียมการ (Inspection & Context)
1. ตรวจสอบเฉพาะไฟล์และโค้ดที่เกี่ยวข้องกับฟังก์ชันที่ต้องเพิ่ม
2. ใช้ข้อมูลจากการตรวจสอบที่มีอยู่แล้ว ไม่ค้นหาข้อมูลเดิมซ้ำ
3. ใช้ Roblox MCP เฉพาะเมื่อจำเป็นต่อการทำงานจริงเท่านั้น
4. ห้ามเรียก Tool หรือ MCP ซ้ำโดยไม่มีเหตุผลหรือข้อมูลใหม่ที่ต้องการ
5. เมื่อมีข้อมูลเพียงพอแล้ว ให้เริ่มแก้ไขโค้ดทันที

## 2. กฎการพัฒนาและแก้ไขโค้ด (Coding & Development)
6. ห้ามแก้ไขระบบเดิมหรือไฟล์อื่นที่ไม่เกี่ยวข้อง
7. ห้ามสร้างระบบใหม่ทับระบบเดิม หากสามารถนำระบบเดิมมาใช้ได้
8. ไม่ต้องอธิบายหรือรายงานความคืบหน้าทุกขั้นตอน ให้เน้นลงมือทำ
9. หากติดปัญหา ให้ระบุปัญหาและสาเหตุอย่างชัดเจน ห้ามวนค้นหาหรือทดลองซ้ำโดยไม่มีแนวทางใหม่

## 3. กฎการทดสอบ (Verification)
1. ทดสอบเฉพาะฟังก์ชันที่เพิ่มหรือแก้ไข
2. ตรวจสอบผลลัพธ์จากระบบจริงเท่าที่เครื่องมือรองรับ
3. ตรวจสอบว่าไม่มีการแก้ไขหรือทำให้ระบบเดิมเสียหาย
4. ห้ามรายงานว่าทำสำเร็จ หากยังไม่ได้ตรวจสอบผลลัพธ์

## 4. มาตรฐานการรายงานผลเมื่อทำงานเสร็จ (Completion Report)
เมื่อทำงานเสร็จ ให้รายงานกระชับเพียง 4 หัวข้อ:
- **ฟังก์ชันที่เพิ่มสำเร็จ**
- **ไฟล์ที่แก้ไข**
- **ผลการทดสอบ**
- **ปัญหาที่ยังเหลือ (ถ้ามี)**

> **หลักการสำคัญ:** ให้ความสำคัญกับการทำงานให้เสร็จอย่างถูกต้อง รวดเร็ว ไม่ค้นหาข้อมูลหรือวิเคราะห์ซ้ำโดยไม่จำเป็น

## กฎควบคุมการใช้ Roblox MCP (สำคัญ)

1. ก่อนเรียก Roblox MCP ให้ตรวจสอบก่อนว่ามีข้อมูลจาก Dump หรือผลลัพธ์เดิมอยู่แล้วหรือไม่
2. หากมีข้อมูลเพียงพอ ห้ามเรียก MCP เพื่อค้นหาข้อมูลเดิมอีก
3. ค้นหาเฉพาะ Script, Function หรือข้อมูลที่เกี่ยวข้องกับปัญหาโดยตรง
4. ห้ามเรียก get-data-by-code หลายครั้งเพื่อค้นหาข้อมูลที่ได้มาแล้ว
5. ห้ามเรียก get-script-content ซ้ำ หากมีเนื้อหา Script ล่าสุดอยู่แล้ว
6. ใช้ผลลัพธ์จาก MCP ครั้งก่อนต่อยอดในการวิเคราะห์ ไม่เริ่มค้นหาใหม่ทุกครั้ง
7. หากต้องเรียก MCP เพิ่ม ต้องมีเหตุผลชัดเจนว่าต้องการข้อมูลอะไร
8. เมื่อพบต้นเหตุแล้ว ให้หยุดสำรวจและเริ่มแก้ไขทันที
9. ห้ามวนค้นหา ตรวจสอบ หรือวิเคราะห์ซ้ำโดยไม่มีข้อมูลใหม่

เป้าหมาย: ลดการเรียก Roblox MCP ที่ไม่จำเป็น และเพิ่มประสิทธิภาพในการแก้ไขโค้ด


## Roblox Executor - Session Protection Rules

เป้าหมาย: ป้องกันการรบกวนเกมและลดความเสี่ยงจากการทำงานของ Script ระหว่างที่ผู้ใช้กำลังเล่นเกม

### กฎการแก้ไขโค้ด

1. สามารถอ่าน วิเคราะห์ และแก้ไขไฟล์ Lua ในเครื่องได้ตามปกติ
2. ห้าม Execute หรือ Inject Script โดยอัตโนมัติ
3. ห้าม Re-execute Script ระหว่างที่เกมกำลังทำงาน
4. ห้ามแก้ไขหรือโหลด Script ใหม่เข้า Session ที่กำลังเล่น
5. ห้ามสั่ง Disconnect, Rejoin, Restart หรือปิดเกม
6. ห้ามเรียก RemoteEvent หรือ RemoteFunction เพื่อทดลองกับเกมของบุคคลอื่น
7. ห้ามทดลองคำสั่งที่เปลี่ยนสถานะเกมหรือส่งผลต่อผู้เล่นอื่น
8. ใช้ Static Analysis ตรวจสอบ Syntax และข้อผิดพลาดก่อนรายงานผล
9. แยกการแก้ไขไฟล์ออกจากการทดสอบในเกมอย่างชัดเจน
10. เมื่อแก้ไขเสร็จ ให้หยุดและรายงานผล ไม่ Execute เอง

### กฎการจัดการ Session

1. ห้ามควบคุม Session เกมที่กำลังทำงานโดยไม่ได้รับอนุญาต
2. ห้ามพยายามหลบเลี่ยง Anti-Cheat หรือระบบ Kick ของเกม
3. หากพบข้อผิดพลาดที่อาจเกี่ยวข้องกับระบบป้องกันของเกม ให้หยุดและแจ้งผู้ใช้
4. ห้ามรับประกันว่าจะป้องกัน Error 267 ได้ 100%

### รายงานผล

เมื่อแก้ไขเสร็จ ให้แจ้ง:
- ไฟล์ที่แก้ไข
- ฟังก์ชันที่เพิ่มหรือแก้ไข
- ผลตรวจสอบ Syntax
- ข้อผิดพลาดที่พบ
- สถานะการทดสอบ (ยังไม่ได้ทดสอบในเกม)
