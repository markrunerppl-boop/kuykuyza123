# AGENTS.md - คู่มือและกฎการทำงานสำหรับ AI Agent (Kuykuy Hub Project)

เป้าหมาย: เพิ่มฟังก์ชันตามที่ระบุให้สำเร็จ โดยใช้เวลาและทรัพยากรให้น้อยที่สุด โดยไม่ลดคุณภาพและความถูกต้องของระบบเดิม

## 1. กฎการตรวจสอบและเตรียมการ (Inspection & Context)
1. ตรวจสอบเฉพาะไฟล์และโค้ดที่เกี่ยวข้องกับฟังก์ชันที่ต้องเพิ่ม
2. ใช้ข้อมูลจากการตรวจสอบที่มีอยู่แล้ว ไม่ค้นหาข้อมูลเดิมซ้ำ
3. ใช้ Roblox MCP เฉพาะเมื่อจำเป็นต่อการทำงานจริงเท่านั้น
4. ห้ามเรียก Tool หรือ MCP ซ้ำโดยไม่มีเหตุผลหรือข้อมูลใหม่ที่ต้องการ
5. เมื่อมีข้อมูลเพียงพอแล้ว ให้เริ่มแก้ไขโค้ดทันที

## 2. กฎการพัฒนาและแก้ไขโค้ด (Coding & Development)
6. ห้ามแก้ไขระบบเดิมหรือไฟล์อื่นที่ไม่เกี่ยวข้อง
7. ห้ามสร้างระบบใหม่ทับระบบเดิม หากสามารถนำระบบเดิมมาใช้ได้
8. ไม่ต้องอธิบายหรือรายงานความคืบหน้าทุกขั้นตอน ให้เน้นลงมือทำ
9. หากติดปัญหา ให้ระบุปัญหาและสาเหตุอย่างชัดเจน ห้ามวนค้นหาหรือทดลองซ้ำโดยไม่มีแนวทางใหม่

## 3. กฎการทดสอบ (Verification)
1. ทดสอบเฉพาะฟังก์ชันที่เพิ่มหรือแก้ไข
2. ตรวจสอบผลลัพธ์จากระบบจริงเท่าที่เครื่องมือรองรับ
3. ตรวจสอบว่าไม่มีการแก้ไขหรือทำให้ระบบเดิมเสียหาย
4. ห้ามรายงานว่าทำสำเร็จ หากยังไม่ได้ตรวจสอบผลลัพธ์

## 4. มาตรฐานการรายงานผลเมื่อทำงานเสร็จ (Completion Report)
เมื่อทำงานเสร็จ ให้รายงานกระชับเพียง 4 หัวข้อ:
- **ฟังก์ชันที่เพิ่มสำเร็จ**
- **ไฟล์ที่แก้ไข**
- **ผลการทดสอบ**
- **ปัญหาที่ยังเหลือ (ถ้ามี)**

> **หลักการสำคัญ:** ให้ความสำคัญกับการทำงานให้เสร็จอย่างถูกต้อง รวดเร็ว ไม่ค้นหาข้อมูลหรือวิเคราะห์ซ้ำโดยไม่จำเป็น
